# React · помощник для Windows

Локальное Electron-приложение для тренировок и согласованных с участниками собеседований. Слушает системный звук Windows и по кнопке или **Ctrl+Alt+Space** показывает краткий ответ на последний вопрос.

## Запуск

Нужен установленный Node.js (на этом компьютере уже есть).

```powershell
cd C:\dev\other\xz\interview-assistant
npm install
npm start
```

После установки зависимостей можно запускать двойным кликом по `start.cmd`.

Приложение отображается только значком в системном трее, без кнопки в панели задач. Нажатие на значок показывает или скрывает окно; правая кнопка открывает меню. Сворачивание и крестик прячут окно в трей, сохраняя ключ и сессию в памяти. Для полного завершения выберите «Выход» в меню трея. Если захват звука включён, он продолжает работать при скрытом окне. Запуск через `start.cmd` не оставляет открытой консоль. Windows может поместить значок в меню скрытых значков рядом с часами.

1. По умолчанию выбран **Groq**. Создайте ключ в [Groq Console → API Keys](https://console.groq.com/keys), вставьте в поле «Groq API-ключ» и нажмите «Применить». Не отправляйте ключ в чат. Можно также задать `GROQ_API_KEY` перед запуском. Для Gemini и OpenAI предусмотрены отдельные ключи: `GEMINI_API_KEY` и `OPENAI_API_KEY`. Ключи из интерфейса хранятся только в памяти и не передаются другому провайдеру. Для загрузки при каждом запуске заполните `local.env` рядом с `start.cmd`: `GROQ_API_KEY=ваш_ключ`. Для других сервисов поддерживаются `GEMINI_API_KEY` и `OPENAI_API_KEY`. Файл исключён из Git, ключ в нём хранится обычным текстом. Переменные окружения имеют приоритет. После изменения файла полностью выйдите через трей и запустите приложение заново; настройки автоматически скроются, если ключ загружен. Ввод в интерфейсе не изменяет файл. Образец без ключей: `local.env.example`.
2. Сначала проверьте текстовый вопрос. Для бесплатного Groq используйте **Free Plan**: запросы ограничены квотами, при превышении API возвращает ошибку 429. Для платного аккаунта применяются его тарифы. Приложение не подключает оплату. Для Gemini нужен проект с доступным Free Tier; подписка Google AI Pro не заменяет тариф API. OpenAI API оплачивается отдельно от подписки ChatGPT.
3. В Jazz выберите устройство вывода, совпадающее с устройством Windows по умолчанию. Используйте наушники. Выключите музыку и звуки уведомлений.
4. Нажмите «Начать захват звука». Включите речь в тестовом звонке и убедитесь, что индикатор двигается.
5. После вопроса нажмите **Ctrl+Alt+Space** или кнопку подсказки. По умолчанию отправляются последние 60 секунд, можно выбрать 20 или 40. Groq использует `whisper-large-v3-turbo` для распознавания и `openai/gpt-oss-120b` для ответа. Оба запроса идут в Groq; несмотря на имя модели, ключ OpenAI не нужен. Gemini получает WAV и возвращает вопрос с ответом за один запрос. OpenAI использует два запроса. Время зависит от сети, длительности фрагмента и моделей.
6. «Остановить захват» отключает источник и стирает аудиобуфер. «Очистить» удаляет текущий текст, предыдущий контекст и аудиобуфер. «Отменить» прерывает ожидающий запрос, но не отзывает уже отправленные данные.

## Что именно работает локально

Окно, захват звука и кольцевой буфер находятся на компьютере. Распознавание и генерация ответа — в выбранном API через интернет. В режимах Groq и Gemini OpenAI не вызывается. Аудио отправляется только по запросу подсказки. Микрофон не захватывается, поэтому ваши собственные ответы могут отсутствовать в контексте. Приложение хранит последние четыре успешные расшифровки/вопроса в памяти и передаёт их для уточняющих вопросов. Это не непрерывная расшифровка всей встречи. Gemini показывает выделенный последний вопрос, а не дословную расшифровку всего фрагмента.

Записи и история на диск не сохраняются самим приложением. Для генерации OpenAI установлено `store: false`; это не обещание отсутствия серверных журналов провайдера. На бесплатном тарифе Gemini данные могут использоваться Google для улучшения продуктов. Захватывается весь системный звук, а не только Jazz. Electron запрашивает поток экрана для доступа к loopback-аудио; приложение не показывает, не записывает и не отправляет видеокадры.

В Windows включено исключение окна из захвата через Electron `setContentProtection(true)`. Само окно остаётся видимым владельцу, можно включить «Поверх окон». Поведение зависит от способа захвата: перед использованием проверьте демонстрацию в Jazz со стороны второго участника. Это не скрывает процесс приложения или значок в трее и не гарантирует исключение из всех видов записи.

## Если не работает

- **ERR_CONNECTION_CLOSED / RESET:** приложение один раз закрывает старое соединение и повторяет запрос через тот же прокси. Повтор может расходовать квоту, если сервис успел обработать исходный запрос. В настройках есть «Проверить подключение»: после «Применить» проверяет доступ к списку моделей с вашим ключом без отправки аудио или вопроса. Успешная проверка не гарантирует доступную квоту генерации.

- **Тишина:** проверьте вывод Jazz и Windows, проиграйте речь, перезапустите захват после смены наушников. Индикатор должен двигаться.
- **401:** неверный API-ключ. **429:** квота, лимит или API-баланс. **403:** проверьте ключ, регион и разрешения проекта. **404:** измените имя модели на доступную вашему аккаунту.
- **Горячая клавиша занята:** используйте кнопку.
- **Нет сети или API недоступен:** облачные функции не работают. Полностью офлайн-моделей в этом прототипе нет.
- **Ошибка в подсказке:** исправьте вопрос вручную. Ответы модели и распознавание могут ошибаться, особенно с терминами и оборванными вопросами.

## Проверка

`npm test` проверяет аудиобуфер, WAV, настройки прокси и формирование/разбор запросов Gemini. `npm run test:smoke` проверяет настоящее окно, IPC, OpenAI/Gemini/Groq, разделение ключей, ошибки квот, оборванные ответы и отмену на подставных ответах. `npm run test:visual` открывает окно, проверяет его видимость, стили и кнопку «Поверх окон». Захват Jazz и реальные ответы API нужно проверить на тестовом звонке с вашим ключом.

## Прокси

Для этого компьютера задан `http://127.0.0.1:9697`. Запустите свой прокси-клиент перед использованием помощника. В разделе «Прокси» можно изменить адрес; пустой адрес использует системные настройки. Поддерживаются HTTP/HTTPS и SOCKS5 без авторизации; для HTTP/HTTPS есть отдельные поля логина и пароля. Пароль хранится только в памяти. После изменения нажмите «Применить». Настройки действуют только на API-запросы приложения, системный прокси Windows не меняется.

Проверка `node launch.cjs test/proxy-check.cjs` отправляет через этот локальный HTTP-прокси запрос списка моделей Groq без ключа и пользовательских данных. Ответ 401 «Invalid API Key» подтверждает сетевое соединение, но не наличие квоты или доступ к конкретной модели. Прокси сам по себе не предоставляет квоту и не меняет условия доступности сервиса.

Groq: [бесплатные лимиты](https://console.groq.com/docs/rate-limits), [распознавание речи](https://console.groq.com/docs/speech-to-text).

Gemini: [биллинг и Free Tier](https://ai.google.dev/gemini-api/docs/billing), [обработка аудио](https://ai.google.dev/gemini-api/docs/audio).

Основания реализации: [Electron desktopCapturer](https://www.electronjs.org/docs/latest/api/desktop-capturer/), [OpenAI: расшифровка аудио](https://developers.openai.com/api/docs/guides/speech-to-text), [OpenAI: генерация текста](https://developers.openai.com/api/docs/guides/text).
